# Lock Screen Wallpapers

Default wallpapers for the Apple-style lock screen.

To add a custom wallpaper:
1. Add your image file to this directory
2. Update the wallpaper path in the LockScreen component

Recommended:
- Resolution: 2560x1600 or higher
- Format: JPG or PNG
- Size: Optimize for web (under 2MB)

You can use beautiful macOS wallpapers from:
- https://photos.app.goo.gl/... (your personal photos)
- https://unsplash.com (free high-quality images)
- https://www.pexels.com (free stock photos)
