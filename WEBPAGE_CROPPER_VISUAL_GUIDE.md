## Quick Reference

| Mode | Icon | Color | What You Can Do |
|------|------|-------|-----------------|
| **Edit** | ✏️ | Purple | Interact, search, scroll, click |
| **Crop** | 📐 | Green | Draw selection area |

## Pro Tips

1. **Search First:** Use Edit Mode to find exactly what you want before cropping
2. **Resize Later:** Create widget at any size, adjust later with resize handles
3. **Fullscreen:** Click widget to view fullscreen, press ESC to close
4. **Recreate:** Not happy? Delete and create a new one with different area
